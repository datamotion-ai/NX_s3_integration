# S3 Storage Plugin

This is a dynamic library that implements remote storage functionality with an S3 server as a
backend, as a Storage Plugin for the VMS Server, built using Storage SDK.

Version 1.0

Resolved issue:

1. issue:empty folder created: 
root cause: while doing folder exist api call it gives garbage name from server. which is created when this name is not exist
fix: removed folder creation on folder exist code

2. issue:file read/write on same time: 
root cause:temp file name for read and write is unique name generated by syatem. some times when it is created at same time it gives same name for read/write gives override the file causes issue in file operation.
fix: resolved issue by give usnique name prefixed as "read", "write" to diffrenciate unique name for read and write operation
